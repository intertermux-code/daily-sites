/ FEATURES

Five instruments.
One flight deck.

Every feature is a panel on the same console — shareable, addressable, and bound together by a single query language and a command palette.

01 / STREAMS

Live telemetry, without the lag.

Ingest structured events at wire speed. Pulseboard's columnar stream holds 72 hours of raw data hot, with a tail latency under 300 ms from producer to pane. Backfill is a first-class operation — replay any window, re-derive any metric, rewind any incident.

  • 01 Schema-on-write with auto-detection
  • 02 Tail, filter, fork — in the same keystroke
  • 03 Cross-region fan-in, single pane of glass
  • ⌘E explore
  • ⌘⇧F live tail
02 / DETECT

Alerts that arrive with receipts.

Pulseboard couples static thresholds with learned baselines so you stop chasing noise. Every firing alert carries the query, the contributing series, the recent change set, and a one-click fork into an investigation workspace.

“Our on-call engineers read alerts like stories now, not like riddles.”

— Naya Rhee, Eng Manager, Orbital
  • A Baseline learned per series, per day-of-week
  • B Multi-signal correlation (logs ↔ traces ↔ metrics)
  • C Severity auto-tuned from downstream impact
03 / QUERY

Ask the board anything.
Get a typed answer.

editor.pbq · saved · 2m ago 
1 from events
2 where service = "checkout-svc"
3   and status >= 500
4 group by 1m
5 select
6   count() as errors,
7   percentile(latency, 0.95) as p95
8 order by t desc
9 limit 240

A typed query language, purpose-built for observability. PBQ feels like SQL but understands traces, spans, and time buckets natively. Autocomplete is aware of your schema, your saved queries, and the shape of yesterday's incident.

  • 01 Autocomplete trained on your own schema
  • 02 Joins across metrics, logs, and traces
  • 03 Explain plan shows exactly which shards are hit
  • 04 Export any query to Grafana, Terraform, Python
  • ⌘K palette
  • ⌘↵ run
  • ⌘. explain
04 / SLO

Error budgets, not error reports.

Define SLOs in plain language — “99.9% of checkout requests succeed in under 400ms” — and Pulseboard computes the budget in real time. You see the burn rate, the forecasted exhaustion date, and the top three contributing services.

  • A Budget-aware alerting (not threshold-based)
  • B Burn-rate forecasts with 14-day horizons
  • C One-click contributor drill-down

The command palette that binds it all.
