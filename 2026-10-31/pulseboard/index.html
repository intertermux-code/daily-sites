Ingest: your events arrive already trusted

Drop the SDK, point the warehouse connector, or stream straight from Kafka. Pulseboard validates every event against your schema at the door, quarantines malformed rows instead of silently dropping them, and backfills history without a second pipeline.

  • Schema contract — 218 validation rules run before a byte is stored
  • Replay buffer — 30-day raw retention, re-model history without re-instrumenting
2.4 B events / day
0.03% rejected rows
60 s reconcile interval

Model: one definition, everywhere it is used

You define “activated account” once, in a metric tree that behaves like code. Pulseboard propagates it to every board, funnel, and alarm, then shows who depends on it before you change it — so two teams never report different numbers to the same executive.

  • Versioned metrics — diff, roll back, and annotate every definition change
  • Impact graph — see the 14 boards a single edit will move
86 metrics per team
0 conflicting definitions
5 min median edit to publish

Act: the board tells you when to move

Alarms watch both hard thresholds and learned behaviour, then open a thread with the context attached: which metric moved, what it broke down into, which deploy or campaign landed in the same window. You get a hypothesis on the way to the room instead of after it.

  • Attribution notes — segment-level breakdown shipped with every alert
  • Quiet routing — escalation paths, snooze windows, and on-call rotations
41 s detection to notice
73% of alarms closed same day
